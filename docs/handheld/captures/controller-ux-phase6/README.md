# Phase 6 — native desktop runtime captures

All 23 individual images are 512×384 logical pixels, rendered by the production
Explorer/menu and native X8 viewport in `ManagementUxTests`. The deterministic
native fixture uses privately installed original G1 graphics and official objects.
Ledger/history/research/ride fixture values are initialized for assertions; these
are not real mature-park financial records. Images are not mockups or hardware
screenshots. No original asset files or archives are included.

The user explicitly authorized repository publication of these and the completed
Phase 7 screenshots. `contact-sheet.png` is a presentation montage of eight
unchanged individual runtime frames. Individual files remain available below.
