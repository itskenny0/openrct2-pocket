# Phase 8B native runtime captures

Each numbered PNG is an actual 512×384 desktop runtime capture using production
UI and installed native RCT2 park assets. These are deterministic fixtures, not
physical Brick screenshots. Proprietary source assets are not included.

`cases.json` maps each capture to its fixture. `contact-sheet.png` is an index;
inspect individual numbered PNGs at logical size. `before-after.png` compares
the same Dashboard, Guest Needs and Coaster Build fixtures with Phase 8A.

Known wide Fill panel occlusion is retained as P7-01. Empty background areas in
management fixtures are native owned grass, not generated mockups.
