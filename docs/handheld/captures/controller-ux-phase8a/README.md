# Native runtime comparisons — Phase 8A

Before: canonical d4e6993. After: Phase 8A shared visual polish.

Every individual image is 512×384 desktop offscreen runtime output from the
production UI/native renderer with installed RCT2 assets. Fixture records are
seeded for deterministic testing. No physical Brick verification is claimed.

`cases.json` maps the 15 required cases within the complete delivered bundle.
The repository includes all after images and the five matched before examples
used in the comparison sheet; the capture bundle contains the complete before set.
`contact-sheet.png` contains those 15 after cases at native image size.
`before-after.png` compares five matching cases without enlarging their pixels.

Additional images include native guest need extremes, staff patrol, long roster
paging, full thoughts, review dialogs, path rejection and partial-build outcomes.
See `../../CONTROLLER-UX-PHASE8A.md` for scope, build/tests and remaining issues.
