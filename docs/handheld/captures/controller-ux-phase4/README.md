# Phase 4 runtime captures

These 12 PNGs are 512×384 native viewport and production UI captures from
`RideFlowTests`, executed as AArch64 code under QEMU with the user’s privately
supplied original RCT2 assets. The scenario fixture uses real native purchases,
geometry, status changes and accounting. They are not physical Brick screenshots
or generated mockups. No original asset files are included.
