# Ten-minute first playtest

- Launch from NextUI Tools; confirm the title/menu is visible and readable.
- Check physical A confirms and B backs out; check X/Y, Start/Select, L1/R1,
  L2/R2 and D-pad. Report any swapped/missing button and send launch.log.
- Load a small real scenario. Check the 4:3 view fills 1024×768 without cropping;
  the logical 512×384 panels, focus and cursor should remain crisp at 2×.
- Pan, rotate and zoom. Check selection stays under the intended native cursor.
- Extend a normal path and a queue; try one ordinary slope and remove a mistake.
- Place several trees/decorations with separate A presses without reopening the
  picker. Adjust height, reset automatic height, rotate, and cancel an invalid site.
- Place a supported flat ride, its entrance/exit and access paths; open management.
- Check pause/menu return and held A: no repeated purchase or confirmation spill.
- Save to a Pocket slot or named native .park. Exit through Save and Exit.
- Launch again, reload that park, and verify the path, scenery and ride remain.
- Confirm normal exit returns to NextUI. Report sound, stalls, memory errors,
  readability and responsiveness. Do not infer FPS from this unmeasured build.

Stop on a crash or lost save; preserve the log and affected .park before retrying.
Next work should fix observed hardware blockers before expanding feature parity.
